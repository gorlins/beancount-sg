Credit Card Rewards

How to set up

Add rewards metadata to a credit card's open directive:

2020-01-01 open Liabilities:CreditCard:Sapphire USD
  rewards: "points"            ; or "cashback"
  rewards-rate: 1              ; the default rate (defaults to 1)
  rewards-rate-dining: 3       ; a category's rate: rewards-rate-<category>
  rewards-unit: "UR"           ; points only: what the points are called
  rewards-point-value: 0.0125  ; points only, optional: a point's cash value
  • A rate of 3 means 3% back for cashback, or 3 points per unit spent for points.
  • Spending is a card's charges to Expenses accounts, grouped by each posting's category metadata, or else its transaction's. Category rate keys are the category in lowercase with dashes: Food and Drink uses rewards-rate-food-and-drink. Spending without a category is uncategorized and earns the default rate.
  • Only transactions in the current Fava filter (e.g. the time range) are counted.
  • The charts show spend and the rewards' cash value by card and category. Points count towards value only with a rewards-point-value.
